# ДЗ 7. MCP-сервер обліку витрат

Сервер тримає особистий список витрат і віддає його моделі: додати витрату,
подивитись підсумок за категорією, переглянути останні записи, видалити зайвий.
Дані лежать у `expenses.json` поруч зі скриптом (шлях можна змінити через
змінну середовища `EXPENSES_FILE`); файл створюється сам при першому записі.

## Інструменти

| інструмент | що робить | що повертає на помилковий вхід |
|---|---|---|
| `add_expense(amount, category, note="")` | записує витрату | сума ≤ 0 або порожня категорія — текст із поясненням, запису немає |
| `category_summary(category)` | кількість, сума, середнє і максимум за категорією | категорії немає — текст зі списком наявних категорій |
| `list_expenses(limit=10)` | останні витрати рядками + загальна сума | витрат немає — «Витрат ще немає»; `limit < 1` — одна витрата |
| `delete_expense(expense_id)` | видаляє витрату за номером | номера немає — текст із переліком наявних номерів |

Ресурси «тільки для читання»: `expenses://all` — усі витрати одним текстом,
`expenses://categories` — сума за кожною категорією, від більшої до меншої.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

```bash
mcp dev server.py     # сервер + MCP Inspector у браузері
```

```bash
mcp install server.py # під'єднати до Claude Desktop (потім повністю перезапустити застосунок)
```

Вручну в `claude_desktop_config.json` — тільки абсолютні шляхи:

```json
{
  "mcpServers": {
    "expense-tracker": {
      "command": "/абсолютний/шлях/lesson7/.venv/bin/python",
      "args": ["/абсолютний/шлях/lesson7/server.py"]
    }
  }
}
```

## Найважче

Найважче було не написати код, а написати docstring: інструмент,
який ідеально працює в Inspector, модель не викликає жодного разу, поки в описі
немає прямої відповіді на питання «коли саме мене брати».
